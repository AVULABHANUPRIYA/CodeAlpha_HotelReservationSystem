CodeAlpha Hotel Reservation System

This project is developed as Task 4 of my CodeAlpha Java Programming Internship.

📌 About the Project

The Hotel Reservation System is a simple Java-based application that allows users to view available rooms, make reservations, and manage hotel bookings.

The project is designed to practice basic Java programming and Object-Oriented Programming concepts.

✨ Features

- View available hotel rooms
- Book a room
- Manage reservations
- Take user input
- Display reservation details
- Simple menu-based interaction

🛠️ Technologies Used

- Java
- Object-Oriented Programming
- VS Code

▶️ How to Run

1. Download or clone this repository.
2. Open the project in VS Code or any Java-supported IDE.
3. Compile the Java file.
4. Run the program.
5. Follow the instructions displayed in the console.
